### 🧭 About me

I like digging into a problem until I understand what is actually going wrong. Most of the time it is not the model. It is the messy data, the edge case nobody tested, or a demo that looked convincing and was not.

- 🔍 Built a **RAG assistant** that stops outdated policies from ever reaching the LLM
- 🤖 Built a **multi-agent LLM system** where AI agents debate and a moderator decides when they agree
- 🌱 Forecasted **seed longevity** at Corteva Agriscience on ten years of production data
- 🧬 Researched **graph machine learning for drug repurposing** in my MSc thesis at Politecnico di Milano
- 🎯 Currently learning: agents with tool calling and human approval steps, and observability for LLM apps
